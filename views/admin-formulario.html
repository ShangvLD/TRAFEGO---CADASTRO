Configurar o formulário

Defina quais operações aparecem no formulário e qual documento cada uma exige. As mudanças valem na hora, sem precisar de deploy — o formulário lê esta configuração a cada abertura.

grid_on Documentos

—

Marque em quais operações cada documento é exigido. A coluna Todas vale para qualquer operação — útil para documento universal como a CNH. Desmarcando Todas, escolha as operações uma a uma.

quiz Perguntas do formulário

—

As perguntas que aparecem para quem preenche. O tipo define como o valor é conferido — CPF confere o dígito verificador, placa aceita o formato antigo e o Mercosul, e assim por diante.

warning Este formulário ainda é desenhado à mão. A tela de cadastro do terceiro (/cadastro) tem os 18 campos escritos direto no HTML, e a validação dele é a de validarCadastro. Enquanto for assim, o que você mudar aqui não muda nada para quem preenche — a configuração está pronta, quem falta converter é a tela.
